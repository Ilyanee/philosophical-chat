# Philosophical Chat Project
This project aims to give a structure for anyone to be able to train a generative model replicating famous writers for instance.
Only requirement is to provide the corpus used for training.

# Why this project
By using a generative model trained on a sufficient amount of data, we could grasp what a discussion with some writers from centuries ago would be.
This could make room for a better understanding of older works and allow more people to discover books that they thought unaccessible for them.
